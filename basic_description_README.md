YOLOChain: Blockchain-Enabled Smart Surveillance with Post-Quantum Security

This repository provides the implementation and experimental materials
associated with the YOLOChain research study.

The repository contains:

- Ablation experiments (A–D)
- Post-quantum cryptography benchmarks
- KEM and digital-signature benchmarks
- Validator scalability experiments
- Security evaluation scenarios
- Reproducibility scripts and configuration files

YOLOChain integrates YOLOv8-based object detection with MQTT communication,
permissioned PBFT-style blockchain processing, and post-quantum cryptographic
primitives.

The repository is intended to support reproducibility of the experimental
results reported in the manuscript.
